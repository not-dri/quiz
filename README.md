HOW TO RUN IT LOCALLY:
### Installation & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd quiz
   ```

2. **Run the project:**
   * **Option 1 (Simple):** Double-click the `index.html` file to open it directly in your web browser.
   * **Option 2 (Recommended):** Use a local development server like VS Code's **Live Server** extension, or run Python's built-in server in your terminal:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.
